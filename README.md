**Design Choices (early):**
Black background less harsh, easier to use. Gives more interigty and feels less corporate. Makes the illustrations of the highest contrast/draws eyes there rather then background.

Using traditional drawings, scanned in then image traced in Illustrator to great more subtle texture and feel more authentic/'real'. Feels like it re-iterates the point of the webpage more. I've been making sure these work together and side by side, factoring in the text placement while drawing.

**Research**
